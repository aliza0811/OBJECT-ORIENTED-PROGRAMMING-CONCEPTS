# OBJECT-ORIENTED-PROGRAMMING-CONCEPTS
**The world of OOP is built on 4 important concepts**. 
1. Class
2. Method
3. Object
4. Function

**Object** is the data/attributes/properties that is held by a class. 
**Method** is the action that it performs on the object. 
**Class** is like a blueprint/structure/schema/representation overall containing the methods and objects. 
class = Object + Method

*A **class** is a **Keyword**. A keyword is a reserved built-in word that carries a specific meaning and is used to execute a specific task. A keyword cannot be used as a **Variable**.*
